# Capstone-Project

Summary
--------------

The program was requested from the Spartanburg Community College Food Pantry. The 
system requested was needed to manage and track their inventory as well as 
generate needed reports and streamline user sign ups so that they can go from
a paper system to a digital one.

Features
--------------

User Authentication: Secure login system for administrators and staff members.

Inventory Management: Add, update, and delete inventory items with ease.

Search & Filter: Quickly find items using search and filter functionalities.

Generate Reports: Reports for inventory.


Technologies Used
--------------

Frontend: HTML, CSS, Bootstrap, JavaScript

Backend: .NET Core, Entity Framework Core

Database: SQL Server

Architecture: Model-View-Controller

Other: Git
